BETTER BUZZ DEPLOYMENT PROTOTYPE

1. Open index.html on a computer to test the deployment builder.
2. Choose staffing from 4–10.
3. Enter team member names.
4. Tap Start Deployment to see the live floor board.
5. Names are stored locally on that device/browser.

For iPad Home Screen use:
- Put these files on a simple HTTPS website.
- Open the site in Safari on iPad.
- Share > Add to Home Screen.
- The app is already configured to open in a standalone app-style window.

This is a prototype and can be revised before rollout.
